# Изменения

## Выпуск кабинета — 2 октября 2026

- Кабинет поездок: большая интерактивная карта, выбор маршрута кликом,
  поиск по названию/региону, диапазон дат, отметки и сводная дистанция.
- Загрузка всей библиотеки сводками с продолжением после сетевой ошибки;
  полный трек запрашивается по выбору, а не для всех поездок сразу.
- Ручное добавление для PRO: дороги/точки, поиск и координаты, перемещение
  точек, порядок остановок, дата, длительность, гараж, приватное сохранение.
- Понятные состояния подписки, ошибки карты/сети, сохранённой поездки;
  защита черновика и повтор без дублей после потерянного ответа сервера.
- Проверка Apple state, защита от запоздавших ответов после выхода,
  работоспособность с запрещённым localStorage и изоляция старого
  черновика при смене аккаунта в соседней вкладке.
- Адаптация планшета/телефона, обычный указатель мыши в кабинете,
  перевод ru/en и обновлённое описание обработки веб-поездок.

Нужны связанные изменения backend и исправление iOS-синхронизации.
Точные условия публикации и непроверенные живые сценарии — в STATE.md.

Создание поездок включается отдельно серверным флагом после выпуска
совместимого iOS. В первом выкатываемом варианте доступен просмотр.
